# Waystrom System

Dieses Repository ist das **Fundament und Werkzeug** für die Arbeit bei der
**Waystrom GmbH**. Es enthält keine operative Arbeit selbst – die operative
Arbeit (Aufgaben, Tickets, Kommunikation, Tagesgeschäft) läuft in **Notion**
ab. Hier wird festgelegt, **wie** diese Arbeit in Notion strukturiert,
ausgeführt und kontrolliert wird.

## Was hier liegt

- `specs/` – Spezifikationen (Global, Functional, Future, Technical, Visual
  Rules): das Regelwerk, das Gebote und Verbote der Arbeitsweise festlegt.
- `skills/` – Wiederverwendbare Arbeitsweisen/Fähigkeiten, die in Notion oder
  darüber hinaus angewendet werden.
- `user-stories/` – Konkrete Anwendungsfälle aus Sicht der Beteiligten.
- `work-plans/` – Arbeitspläne für laufende/kommende Vorhaben.
- `journal/` – Laufende Einträge: was wurde gemacht, wie wurde es gemacht.
- `tools/` – Tatsächlicher Code (z. B. Notion-API-Skripte, Automatisierungen),
  falls eine Aufgabe nicht nur Struktur, sondern Programmierung erfordert.
- `CHANGELOG.md` – Logger: jede Änderung an diesem System selbst wird hier
  datiert und nachvollziehbar dokumentiert, bevor sie wirksam wird.
- `CLAUDE.md` – Arbeitsregeln für Claude Code in diesem Projekt.

## Grundprinzip

Jeder Baustein ist eigenständig definiert, alle Bausteine bauen aber
langfristig aufeinander auf. Nichts wird isoliert erledigt und nirgends
festgehalten – jede Änderung an der Struktur, den Regeln oder der
Arbeitsweise wird zuerst hier fixiert (`CHANGELOG.md`), bevor sie gilt.
